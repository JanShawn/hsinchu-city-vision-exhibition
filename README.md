# Hsinchu City Vision Exhibition

1080 × 960 展場觸控互動網站，以新竹景點、美食與主題路線為主要入口，延伸到城市文化與未來願景。

## 資料來源

- 景點、餐飲介紹與基本資訊：交通部觀光署「觀光資訊資料庫 V2.1」官方開放資料。
- 圖片：依官方資料名稱對照新竹市觀光旅遊網公開圖片，經限縮官方網域的 Nuxt server route 代理顯示。
- 景點與美食詳情：呈現資料源完整說明，並以 QR Code 連到新竹市觀光旅遊網官方介紹。
- 旅遊推薦：以 API 回傳的真實景點組成舊城、親子藝文與海岸三條策展路線。
- 未來藍圖：四個城市方向可無上限累積選擇，結果保存在同一台展場裝置並即時形成共同願景；每次投票後顯示 2.6 秒確認畫面以避免連續點擊。結果不代表政府政策統計或民調資料。

`/api/tourism` 會在伺服器端下載並整理官方資料，同名資料優先保留 `Description` 不含網址的版本，再快取六小時；前端包含 loading、error、圖片失敗與空資料處理。

## 開發

```bash
npm install
npm run dev
```

## 驗證

```bash
npm run typecheck
npm run build
```

介面以 1080 × 960 為設計基準，並在其他視窗尺寸中等比例縮放。
